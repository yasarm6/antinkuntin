# AntinKuntin 🎪
Neal.fun tarzı eğlenceli, yaratıcı, interaktif mini oyunlar, tuhaf simülasyonlar ve Türk usulü absürt deneyimler platformu.

## 🌟 İçerik & Mini Oyunlar
- ⏳ **Piksel Kum Havuzu (Sandboxels)**: 500+ element, lav, su, elektrik, asit ve nükleer reaksiyonlarla fizik ve kimya simülasyonu.
- 💸 **Türk Zengininin Parasını Bitir**: 100 Milyar TL ile çıtır simitten Togg'a, Boğaz yalısından Süper Lig kulübüne para harcama simülatörü.
- 🇹🇷 **Şu Anda Türkiye'de Ne Oluyor?**: Sayfayı açtığınız andan itibaren demlenen çaylar, basılan kornalar ve satılan simitler.
- 🪙 **Maaşınla Ne Alabilirsin?**: Asgari ücret veya kişisel maaşla fıstık, altın ve Boğaz geçişi hesabı.
- 🚌 **Zincirlikuyu Metrobüs Simülatörü**: Kapılar açılınca içeri dalma refleks oyunu.

## 🚀 Canlı Yayınlama (GitHub Pages)
Bu repoyu GitHub Pages ile anında ücretsiz yayınlayabilirsiniz:
1. GitHub reponuzda **Settings (Ayarlar)** sekmesine gidin.
2. Sol menüden **Pages** seçeneğine tıklayın.
3. Branch olarak `main` ve klasör olarak `/ (root)` seçip **Save** butonuna basın.
4. Siteniz birkaç dakika içinde tüm dünyaya açık hale gelecektir!
